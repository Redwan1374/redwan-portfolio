# 🌐 Redwan Ahmed Rafi - Portfolio

A modern, responsive personal portfolio website built using **HTML5** and **Tailwind CSS**. This portfolio showcases my education, technical skills, leadership experience, research publications, achievements, and professional journey as a **Computer Science & Engineering student**.

🔗 **Live Demo:** https://redwan1374.github.io/redwan-portfolio/

---

## 📌 About the Project

This portfolio was developed as an academic project using only **HTML** and **Tailwind CSS**, without any JavaScript or frontend frameworks.

The website is fully responsive and designed with a clean, modern user interface to present my academic background and professional profile.

---

## 🚀 Features

- Responsive design for desktop, tablet, and mobile devices
- Modern and professional UI
- Hero section with profile introduction
- About Me section
- Technical & Professional Skills
- Education timeline
- Experience & Leadership
- Research Publications
- Achievements & Awards
- Contact Information
- Tailwind CSS utility-first styling
- Clean and organized code structure
